# New "ppind" field on the option contract schema

The `OptionContract` schema now documents `ppind` (Penny Program Indicator), a required boolean returned on option contract responses. `true` means the contract is eligible for penny price increments under the Penny Program; `false` means it is not.

## Broker API

* `GET /v1/options/contracts`
* `GET /v1/options/contracts/{symbol_or_id}`

## Trading API

* `GET /v2/options/contracts`
* `GET /v2/options/contracts/{symbol_or_id}`
