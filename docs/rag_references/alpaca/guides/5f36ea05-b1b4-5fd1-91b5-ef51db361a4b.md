# About FIX API

Alpaca FIX (Financial Information eXchange) API

# Introduction

Welcome to the Alpaca FIX (Financial Information eXchange) API! The purpose of this document is to show how the FIX messaging protocol can be used to place orders, receive order updates and trades, replace orders and cancel orders.

## Overview

Our API is based on FIX 4.2 specification. Please reach out to our support for FIX credentials.

## Hours of Operation

FIX connectivity for equities trading is generally available Monday through Friday, with sessions beginning between 3:30 and 4:00 a.m. and ending between 8:00 and 8:15 p.m., New York time. Exact session days and hours may vary by agreement. Contact your Alpaca technical representative to confirm the applicable schedule. Schedule changes and planned maintenance will be communicated by email.
